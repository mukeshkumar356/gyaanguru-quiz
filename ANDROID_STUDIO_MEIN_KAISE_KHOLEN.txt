5. Gradle sync hone dein (2-3 minute lagenge)
   (Bottom mein progress bar dikhega)

APK BANANE KE LIYE:
──────────────────────
Menu: Build → Build Bundle(s)/APK(s) → Build APK(s)

Ya Shortcut: Ctrl+F9

APK milega yahan:
GKQuizAndroid\app\build\outputs\apk\release\

RELEASE APK (Chhoti size) ke liye:
Build → Generate Signed Bundle/APK → APK → Next
(Pehli baar ek keystore banana hoga - Android Studio guide karega)
